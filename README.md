# Commodore 64 Text Adventure Started Pack a.k.a Intro to BASIC example

This is a small, bare bones BASIC program that attempts to teach some fundamentals quickly with a working example. This short textadv.bas file demonstrates how to:

- print text to the screen
- let the user type in some text
- read what the user types to do something conditionally with it
- set the color of the text
- set the color of the screen border
- set the color of the screen background
- jump to a different section of code with a GOTO statement

# Commands to know

- PRINT writes text to the screen
- INPUT reads input from user
- IF conditional logic
- GOTO jumps to a different line number in your code
- END quits the program
- POKE writes data to RAM, used for many purposes and is essential for the commodore 64

See Commodore's official programmers manual: https://archive.org/details/c64-programmer-ref/page/324/mode/2up

# How to get started on windows

Install C64 Studio: https://www.georg-rottensteiner.de/files/C64StudioRelease.zip

Install VICE Emulator: https://sourceforge.net/projects/vice-emu/files/releases/binaries/windows/GTK3VICE-3.10-win64.zip/download

When you open C64 Studio it will ask you to point to the path of the emulator which is `[where you extracted the zip]\GTK3VICE-3.10-win64\bin`

Select WinVice from the drop down:
